# Запуск и верификация аппаратной платформы STM32H750

В рамках проекта «Нейросетевой вычислительный контур инверсии каротажа» выполнен перенос и запуск бортового вычислителя на микроконтроллере **STM32H750VBT6** (плата **WeAct Studio MiniSTM32H7xx**).

---

## 1. Аппаратная конфигурация

* **MCU:** STM32H750VBT6 (ARM Cortex-M7, 480 МГц, FPU DP/SP, 128 КБ внутренней Flash, 1 МБ встроенной SRAM).
* **Внешняя память на плате:**
  * **8 МБ QSPI Flash (W25Q64):** шина QUADSPI (PB2, PB6, PD11, PD12, PE2, PD13) с поддержкой Memory-Mapped Mode (`0x90000000`).
  * **8 МБ SPI Flash (W25Q64):** шина SPI1.
  * **MicroSD (TF Card):** шина SDMMC1.
* **Интерфейс связи:** USB Type-C (PA11 — USB_OTG_FS_DM, PA12 — USB_OTG_FS_DP).
* **Индикация и управление:**
  * Светодиод `PE3` (Active LOW / Push-Pull).
  * Пользовательская кнопка `PC13` (K1, Pull-Down).

---

## 2. Архитектура прошивки `NEURO_GEO_H750`

1. **Тактирование:**
   * Внешний кварц HSE 25 МГц $\to$ PLL1 ($M=5, N=192, P=2$) $\to$ **SYSCLK 480 МГц**, HCLK 240 МГц.
   * Аппаратный высокоточный генератор **HSI48** $\to$ USB Kernel Clock 48 МГц (без джиттера, независим от PLL).
2. **Кэши ядра:**
   * `SCB_EnableICache()` — кэш команд Cortex-M7.
   * `SCB_EnableDCache()` — кэш данных Cortex-M7.
3. **USB CDC (Virtual COM Port):**
   * Драйвер ST USB Device Middleware настроен на класс Communication Device Class (CDC ACM).
   * VID: `0x0483`, PID: `0x5740` (нативно поддерживается Windows 10/11 драйвером `usbser.sys` без сторонних inf-файлов).
   * Буферы приёма и передачи: по 2048 байт с очисткой D-Cache (`SCB_CleanDCache_by_Addr`).
   * Встроенный обработчик команд: ответ на `ping` строкой `[STM32H750] PONG! Core 480 MHz, USB CDC Ready.` и эхо входных пакетов.
4. **Heartbeat:**
   * Фоновый цикл переключает состояние светодиода `PE3` каждые 200 мс для визуального контроля работы ядра.

---

## 3. Сборка и прошивка без программатора

Проект автономен и собирается установленным на ПК компилятором GNU ARM Embedded Toolchain (`arm-none-eabi-gcc` 12.3):

```bash
cd NEURO_GEO_H750
make -j4
# -> build/NEURO_GEO_H750.elf (28 КБ dec, 19.7 КБ text)
# -> build/NEURO_GEO_H750.hex
# -> build/NEURO_GEO_H750.bin
```

### Прошивка по USB Type-C (ST DFU Bootloader):
1. Перевод платы в режим загрузчика: зажать `BOOT0`, нажать `NRST`, отпустить `BOOT0`.
2. Запись во Flash:
```bash
STM32_Programmer_CLI.exe --connect port=USB1 --download build/NEURO_GEO_H750.hex 0x08000000 --start
```
Время прошивки и запуска: **~1.0 секунда**.

## 4. Результаты тестирования связи

* Плата определилась в Windows как виртуальный COM-порт: **`COM6`** (`USB\VID_0483&PID_5740\365B324F3333`).
* Проведён тест обмена данными на скорости 115200 бод:
  * Запрос: `ping\r\n`
  * Ответ STM32: `[STM32H750] PONG! Core 480 MHz, USB CDC Ready.`
  * Тест эхо-строки `HELLO_CARTOGRAPHER_40SIG` подтвердил целостность приёма и передачи данных.

## 5. План следующего этапа

1. **Размещение весов нейросетей:**
   * Проверка точности инверсии при квантовании весов в FP16 на синтетическом каротаже.
   * Запись весов в 8 МБ внешнюю QSPI Flash (Memory-Mapped) либо чтение с MicroSD.
2. **C-ядро бортовой инверсии:**
   * Реализация прямого суррогата (7 $\to$ 40) и обратной сети (40 $\to$ 7) на чистом Си с CMSIS-DSP.
   * Реализация 150 шагов PGD-Adam и каскада топологий 0/1/2.
3. **Протокол обмена:**
   * Приём пакета из 40 чисел с плавающей точкой $\to$ запуск PGD $\to$ возврат 14 параметров моделей среды.
