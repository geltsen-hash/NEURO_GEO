# ОТЧЕТ ПО КАЛИБРОВКЕ ПРИБОРА

## 1. Назначение документа

Настоящий отчет содержит результаты калибровки 2-параметрической модели наклона приемников для электромагнитного каротажного прибора с наклонными катушками.

---

### 2.1 Структура прибора

- **Передатчики (Tx)**: Tzz1, Tzz2, Tzz4, Tzz5 (вертикальные соленоиды)
- **Приемники (Rx)**: Rzx1, Rzx2 (наклонные катушки под углом к оси прибора)
- **Расстояния L между Tx и Rx**:

  - ch1: Tzz2-Rzx1, L = 2.28 м
  - ch2: Tzz4-Rzx1, L = 3.00 м
  - ch3: Tzz5-Rzx1, L = 1.62 м
  - ch4: Tzz1-Rzx2, L = 2.28 м
  - ch5: Tzz2-Rzx2, L = 0.96 м ← **аномальный канал**
  - ch6: Tzz3-Rzx2, L = 3.00 м
  - ch7: Tzz5-Rzx2, L = 1.62 м

### 2.2 Измерения

Калибровка выполнялась над металлическим листом (модель идеально отражающей границы) на высотах:

Для каждой высоты измерены гармоники вращения:

Канал ch5 (Tzz2-Rzx2, L=0.96 м) показал систематическое отклонение на обоих приборах. Причина: конструктивная особенность данного канала. Канал исключен из калибровки.

## 3. Методика калибровки

### 3.1 Модель

Используется 2-параметрическая модель с эмпирической поправкой на отклонение от закона 1/L³:

```
f(L) = L^b    (где a=1 фиксировано)
```

Параметры калибровки для каждого прибора:
- **b** — показатель в эмпирической поправке f(L)
- **Rzx1** — угол наклона приемника Rzx1 (градусы)
- **Rzx2** — угол наклона приемника Rzx2 (градусы)

### 3.2 Алгоритм

1. Для каждого прибора независимо подбираются b, Rzx1, Rzx2 методом наименьших квадратов
2. Сравниваются значения b между приборами для проверки универсальности
3. Проводится поканальный анализ остаточного разброса углов

### 3.3 Используемое ПО

- Модуль: `empymod_anis_harmonic_calibration.py`
- Скрипт калибровки: `calibration_single.py`

## 6. Физическая интерпретация

### 6.1 Эмпирическая поправка f(L) = L^b

**Теоретический закон затухания дипольного поля в свободном пространстве**: 1/L³ (для прямого сигнала H0).

**Наблюдаемый закон после введения поправки**: ~1/L^(3-b) ≈ 1/L^2.4.

**Применение поправки**: в модели калибровки поправка `L^b` применяется к **нулевой гармонике H0** (прямой сигнал):
```
H0_corrected = H0 * L^b
r1 = H1 / H0_corrected
```

**Важно**: Поправка компенсирует отклонение закона затухания прямого сигнала (H0) от теоретического 1/L³, вызванное:
1. "Tool body effect" — влияние проводящего корпуса прибора (Магнадур 501)
2. Геометрией отражения от границы
3. Взаимодействием корпуса с полем

Первая гармоника H1 не корректируется напрямую — её изменение следует из изменения отношения H1/H0.

### 6.2 Проверка на воздухе

Для подтверждения мультипликативности поправки f(L) требуется дополнительное измерение:
- Поднять прибор на высоту ≥ 10 м над металлическим листом (или удалить лист)
- Измерить гармоники
- Проверить, что H1 ≈ 0 (прямой сигнал не дает первой гармоники)

Если H1 ≠ 0 на воздухе — это подтвердит наличие аддитивного сигнала от корпуса и потребует другой схемы компенсации.

## 7. Применение результатов

### 7.1 Использование в интерпретации

Для обработки полевых данных (обратная операция к калибровке):

```
1. Коррекция H0 для каждого канала j:
   H0_corr[j] = H0_meas[j] / (L[j]^b)   # ДЕЛИМ на L^b!

   Пояснение: при калибровке теоретический H0 умножался на L^b, чтобы
   соответствовать измеренному (реальный сигнал затухает слабее 1/L^3).
   Поэтому для получения "чистого" геологического сигнала нужно разделить
   измеренный H0 на L^b.

2. Вычисление компонент поля:
   Vzx[j] = H1_meas[j] / sin(Rzx[j] в радианах)
   Vzz[j] = H0_corr[j] / cos(Rzx[j] в радианах)

3. Геосигнал:
   S[j] = (Vzz[j] - Vzx[j]) / (Vzz[j] + Vzx[j])

4. Сравнение с теоретической моделью в обратной задаче
```

### 7.2 Рекомендуемые параметры

| Прибор | b | Rzx1 | Rzx2 |
|--------|---|------|------|
| Прибор 1 | 0.595 | 65.30° | 63.12° |
| Прибор 2 | 0.576 | 66.22° | 64.24° |
| Усредненные | 0.59 | — | — |

Для совместной обработки данных обоих приборов рекомендуется использовать индивидуальные параметры для каждого прибора.
