ИСПОЛЬЗОВАНИЕ:
-------------

1. УСТАНОВКА ЗАВИСИМОСТЕЙ:
   Убедитесь, что установлены необходимые пакеты:
   pip install empymod numpy scipy
   
   Опционально (для красивого прогресс-бара):
   pip install tqdm

2. ЗАПУСК КАЛИБРОВКИ:
   
   А) Интерактивный выбор файла (просто запустить):
      python calibration_single.py
      # Откроется диалоговое окно для выбора CSV-файла
      # Если GUI недоступен — будет консольный выбор из списка
   
   Б) Указать файл явно:
      python calibration_single.py <входной_csv> [выходной_txt]
      
   Примеры:
      python calibration_single.py                    # выбор из списка
      python calibration_single.py data.csv         # указать файл
      python calibration_single.py data.csv report.txt  # файл и отчет
   
3. ПРОЦЕСС КАЛИБРОВКИ:
   Во время работы отображается индикатор активности:
   - Вращающийся спиннер (| / - \) показывает что вычисления идут
   - Номер варианта и промежуточная оценка
   - Время работы: 5-15 минут (зависит от количества высот)

4. РЕЗУЛЬТАТ:
   В выходном файле будут параметры:
   - b (показатель в f(L) = L^b)
   - Rzx1 (угол наклона приемника 1)
   - Rzx2 (угол наклона приемника 2)
   - Поканальный анализ
   - Инструкция по применению в интерпретации

ВАЖНО:
------

- Скрипт calibration_single.py ищет модуль empymod_anis_harmonic_calibration.py
  в той же папке, где находится сам скрипт (исправлен путь).
  
- Если нужно использовать системный empymod_anis_harmonic_calibration,
  раскомментируйте строку sys.path.insert() в начале скрипта.

- ПРОВЕРКА КАНАЛОВ: Скрипт автоматически проверяет все каналы на аномальность.
  Для каждого канала вычисляется ошибка калибровки. Канал считается подозрительным,
  если его ошибка в 3+ раза превышает медиану по всем каналам.
  
  Для каждого подозрительного канала выводится запрос:
    "Канал 5 (L=0.96м): ошибка в 4.2 раза выше нормы. Исключить? (y/n):"
  
  Решение пользователя сохраняется в отчет вместе со списком всех проверенных каналов.

- Высоты >= 9м считаются "воздухом" и исключаются из калибровки,
  но используются для проверки (H1 должен быть ~0).

================================================================================

ДОПОЛНИТЕЛЬНЫЕ РЕКОМЕНДАЦИИ:
----------------------------

1. Проведите измерение на воздухе (h >= 10м) для проверки H1 = 0.
   Это подтвердит мультипликативность поправки f(L).

2. Для повторной калибровки с новыми данными просто запустите
   calibration_single.py с новым CSV-файлом.

3. Сохраняйте все результаты калибровки для трассировки изменений.
