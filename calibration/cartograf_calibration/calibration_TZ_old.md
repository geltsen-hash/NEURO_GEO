# Техническое задание по калибровке (предыдущая версия)

## Исходные данные
- CSV-файл с измерениями гармоник `H0`, `H1`, `H2` для всех каналов наборе высот.
- Геометрия прибора: координаты передатчиков и приёмников, список каналов.
- База канала: `L = |Tx_z − Rx_z|`.
- Поправки `ΔL(L)` и `Δh` не используются (после перекалибровки инклинометра модель точна без них): `L_eff = L`.
- Фильтрация точек по высоте не применяется — используются все измеренные высоты.

## Определение углов приёмников по отношению гармоник

### 2.1. Цель
Найти углы наклона приёмников `Rzx1` и `Rzx2`, при которых теоретическое отношение `H1/H0` совпадает с измеренным.

### 2.2. Используемые данные
- Отношение гармоник: **только `H1/H0`**.
- Искомые углы: **по одному для каждой пары `Tx–Rx`** (8 углов). Угол интерпретируется как эффективный наклон приёмника с учётом доворота от корпуса для данной пары. Передатчики считаются вертикальными (`β_tx = 0°`).
- Используются все измеренные высоты для данного канала.

### 2.3. Модель
- Для каждой пары `Tx–Rx` с учётом `L_eff = L` и эффективного угла пары `β_j` рассчитывается `(H1/H0)_theor`.

### 2.4. Метод подбора
- Для **каждой пары `Tx–Rx`** (т.е. для каждого канала) подбирается свой угол `β_j`.
- Критерий: **минимизация суммы квадратов отклонений** `(H1/H0)_theor − (H1/H0)_meas` по всем измеренным высотам данного канала.

### 2.5. Выход
- Таблица углов `β_j` для каждой пары `Tx–Rx` (8 значений) в градусах.
- Сравнение `(H1/H0)_theor` и `(H1/H0)_meas` по каналам и высотам.
- Среднее и максимальное отклонение после подбора.

### 2.6. Проверка
- Углы физически разумны.
- Зеркальные пары остаются симметричными.
- Зависимость от высоты не ухудшается.

## Физическая интерпретация отклонений от модели точечного диполя (1/L³)

### Гипотеза (теория Долля)
- Полный сигнал по теории геометрического фактора (Долль) — сумма вкладов проводящих оболочек, каждый вклад пропорционален произведению геометрического фактора `g` и проводимости `σ` (даёт как амплитудное затухание, так и фазовый сдвиг).
- Металлический корпус прибора расположен очень близко к катушкам: малый геометрический фактор `g_corpus`, но высокая проводимость `σ_corpus` — произведение `g_corpus·σ_corpus` даёт конечную (не исчезающую) поправку к сигналу.
- Корпус влияет главным образом на **прямое прохождение (ZZ)**; на **отражённый сигнал (ZX)** его влияние незначительно.

### Согласованность с данными
- Прямой член сигнала `~1/L³` не зависит от высоты `h`, отражённый (зеркальный) член затухает с `h` (через `2h` в методе изображений). При больших `h/L` прямой (искажённый корпусом) член доминирует.
- Это совпадает с наблюдением: несовпадение измерений с теорией нарастало именно на коротких базах `L` при больших высотах `h` (где доминирует прямой ZZ-сигнал), а не на длинной базе `L=3.00 м`, где отражённый сигнал остаётся значимым на всём диапазоне высот.

### Следствие для подбора угла β
- Амплитудное искажение от корпуса нам неизвестно (не измерено отдельно) и не может быть скорректировано явно.
- Поскольку угол `β_j` — единственный свободный параметр модели для каждой пары `Tx–Rx`, искажение от корпуса **полностью поглощается подбором `β_j`**.
- Из-за этого один и тот же физический приёмник (например, `Rzx1`) даёт **разные подобранные `β`** в зависимости от `L` (т.е. от того, с каким передатчиком он в паре) — хотя физически наклон приёмника один и тот же для всех пар. Разброс `β` по `L` — это индикатор величины неучтённого искажения от корпуса, а не реальная физическая переменная наклона приёмника.

### Наблюдение: монотонная зависимость β(L)
- Подобранный `β` **монотонно убывает с ростом `L`** для обоих приёмников (например, Rzx1: 64.62° → 61.62° → 58.54° → 54.58° при L = 0.96 → 1.62 → 2.28 → 3.00 м).
- Это согласуется с моделью: при увеличении `L` прямой (искажённый корпусом) член `~1/L³` слабеет относительно отражённого, то есть искажение, поглощаемое в `β`, уменьшается.
- Следствие: истинный физический угол приёмника соответствует асимптотике `β(L → ∞)` (экстраполяция тренда `β(L)` на бесконечную базу, где вклад корпуса исчезает).
- **Практическое решение:** экстраполяцию для нахождения "истинного" угла не делаем — удобнее и проще транслировать (поглощать) влияние корпуса непосредственно в калибровочный угол наклона `β_j`, подбираемый отдельно для каждой пары `Tx–Rx`. Это уже реализовано в текущей модели (`β_j` — свободный параметр на канал).

## Природа 2-й гармоники (H2)

### Наблюдение
- Текущая модель (`Tx` строго вертикален, `tx_tilt = 0`) даёт теоретическую `H2/H0 = 0` для всех каналов и высот — отражённая xx-связь принципиально не может возникнуть без наклона передатчика.
- Измеренная `H2/H0` небольшая, но не нулевая (0.01–0.9% на перекалиброванных данных), убывает с высотой.
- Отношение `H2/H1` не является константой (std/mean = 30–61% по каналам) — гипотеза артефакта посадки энкодера (`H2/H1 = const`, см. `model.py: H2_ENCODER_BIAS`) не подтверждается в чистом виде.

### Причина: яйцеобразность/эксцентриситет инклинометра
- Сравнение старых данных (до перекалибровки инклинометра) и новых (`calibration_data_main.csv`, после перекалибровки) на сравнимых высотах (~0.68 м) показывает падение `H2/H0` в **2.7–9.3 раза** (в среднем ~5x) по всем 8 каналам после перекалибровки.
- Это прямо указывает на инклинометр (яйцеобразность/эксцентриситет посадки) как источник `H2`, а не на реальную физическую xx-связь или геометрию прибора (наклон Tx, корпус и т.п.).
- Механизм: искажение формы кривой угла поворота (не идеальная синусоида кодирования угла) даёт утечку энергии во 2-ю гармонику пропорционально общему уровню сигнала — поэтому пропорция к `H1` не постоянна, а `H2` в целом коррелирует с амплитудой сигнала и качеством инклинометра.

### Вывод
- `H2` не несёт полезной информации о геометрии/наклонах прибора в текущей постановке и не используется в калибровке углов `β` (только `H1/H0`).
- Дальнейшее уменьшение `H2` возможно только через дальнейшее улучшение/перекалибровку инклинометра, а не через доработку модели сигнала.
