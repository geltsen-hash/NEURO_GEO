# Техническое задание: моделирование влияния недокалиброванности инклинометра на гармоники

## 1. Постановка задачи

### 1.1. Что наблюдается в данных
- Вторая гармоника `H2` не равна нулю, хотя физическая модель (вертикальный передатчик) предсказывает `H2/H0 = 0`.
- После перекалибровки инклинометра амплитуда `H2/H0` упала в среднем в ~5 раз по всем каналам.
- Отношение `H1/H0` от высоты `h` систематически отклоняется от теории точечного диполя; отклонение растёт с ростом `h/L`.

### 1.2. Физика калибровки угла поворота
- Угловые положения отбиваются по 16 точкам окружности, определяя **магнитный тулфейс (МТФ)** прибора по магнетометру.
- МТФ не совпадает с истинным механическим углом, измеренным транспортиром.
- Расхождение зависит от положения по окружности (гладкая периодическая функция), максимальное отклонение после перекалибровки — **около 1°**.
- Возможные причины: смещение нуля (bias), разные коэффициенты усиления по осям магнетометра, неперпендикулярность осей, эксцентриситет/перекос посадки магнетометра относительно оси вращения.
- Итоговая ошибка описывается угловым сдвигом `δφ(φ_true)` между МТФ и механическим углом.

### 1.3. Гипотеза
- Ошибка `δφ(φ_true)` разлагается в ряд Фурье по `φ_true`.
- **1-я гармоника** `δφ` (эксцентриситет/перекос магнетометра) может порождать `H2` в спектре сигнала, даже если передатчик вертикален.
- **2-я гармоника** `δφ` (разность масштабов по осям, неперпендикулярность) влияет главным образом на `H1/H0(h)` и не порождает `H2` при вертикальном передатчике.
- Высшие гармоники и амплитудная модуляция (wobble корпуса) могут давать дополнительный вклад в `H2`.

## 2. Цель моделирования

Проверить, может ли параметрическая модель ошибки инклинометра объяснить три эффекта **по отдельности**. Совместное подбор параметров под все три эффекта сразу — трудносходимая задача, поэтому исследуем каждый эффект отдельно, в последовательности от простого к сложному.

### 2.1. Подзадача 1: объяснение ненулевой `H2`
- Проверить, какие механизмы ошибки инклинометра (эксцентриситет, яйцеобразность, нелинейность, угловое затухание) приводят к появлению второй гармоники `H2`.
- Оценить амплитуды параметров, необходимые для получения `H2/H0` порядка наблюдаемого (0.01–0.9%).

### 2.2. Подзадача 2: объяснение систематического отклонения `H1/H0(h)`
- Проверить, как те же параметры ошибки инклинометра влияют на `H1/H0` как функцию от высоты.
- Выявить, какие механизмы могут дать характерное для данных отклонение (зависимость от `h/L`, разные знаки ошибки у разных каналов и т.п.).

### 2.3. Подзадача 3: объяснение уменьшения `H2` после перекалибровки
- Сравнить старые данные (до перекалибровки) и новые (после перекалибровки).
- Определить, уменьшение каких параметров модели (`ε_1`, `ε_2`, `a_2` и др.) соответствует наблюдаемому падению `H2` в ~5 раз.

## 3. Исходные данные

- Файл с измеренными гармониками `calibration_data_main.csv` (8 каналов, 8 высот).
- Геометрия прибора (`TRANSMITTERS_Z`, `RECEIVERS_Z`, `CHANNELS` из `model.py`).
- Подобранные углы приёмников `β_j` из текущей модели (`calibration_pipeline.py`).

## 4. Модель ошибки МТФ

### 4.1. Общая форма
Магнитный тулфейс `φ_MTF` (измеренный угол) отличается от истинного механического угла `φ_true`:

```
φ_MTF = φ_true + δφ(φ_true; θ)
```

где `δφ` — гладкая периодическая функция, разлагаемая в ряд Фурье.

### 4.2. Разложение ошибки по гармоникам

```
δφ(φ_true) = φ_0
           + ε_1 · cos(φ_true + ψ_1)
           + ε_2 · cos(2·φ_true + ψ_2)
           + ε_3 · cos(3·φ_true + ψ_3)
```

- `φ_0` — смещение нуля (bias).
- `ε_1` — **1-я гармоника**: эксцентриситет/перекос магнетометра относительно оси вращения.
- `ε_2` — **2-я гармоника**: разные коэффициенты усиления по осям магнетометра или неперпендикулярность осей.
- `ε_3` — высшая гармоника (нелинейность).

### 4.3. Влияние на гармоники сигнала (вертикальный передатчик)
- **1-я гармоника ошибки `ε_1`** смешивает энергию из `H1` в `H2` и обратно; при `ε_1` порядка 1° даёт `H2/H0` порядка 0.5–1%.
- **2-я гармоника ошибки `ε_2`** при вертикальном передатчике не порождает `H2`, но искажает `H1/H0(h)` на уровне нескольких процентов.
- **Bias `φ_0`** эквивалентен повороту всей кривой `S(φ)`; влияет главным образом на эффективный угол `β` и `H1/H0`.
- **Высшие гармоники и амплитудная модуляция** могут давать вклад в `H2`, но требуют отдельной проверки.

### 4.4. Амплитудная модуляция (wobble корпуса, альтернативный механизм)
- Если «яйцеобразность» проявляется как периодическое изменение зазора/усиления сигнала с периодом 2φ:
  `S_mod(φ) = S(φ) · [1 + a_2 · cos(2φ + χ_2)]`.
- Этот механизм напрямую создаёт `H2` даже при вертикальном передатчике; для `a_2` порядка 1% получается `H2/H0` порядка 1%.

## 5. Методика моделирования

### 5.1. Прямое моделирование (forward model)
1. Задать истинный набор углов поворота `φ_true = 0°, 22.5°, ..., 337.5°` (16 точек).
2. Для каждого `φ_true` вычислить `φ_meas = f(φ_true; θ)`.
3. С помощью существующей модели `channel_iq_at_rotation` вычислить комплексный сигнал `S(φ_true)` (direct + image) для заданных `h, L, β`.
4. Интерпретировать `S` как выборку, измеренную в точках `φ_meas`, а не `φ_true`.
5. Применить ту же процедуру FFT (`instrument_harmonics_from_iq`) к этой выборке.
6. Получить гармоники `H0_mod, H1_mod, H2_mod` и отношения `H1/H0`, `H2/H0`.

### 5.2. Сравнение с измерениями
- Для каждого канала и каждой высоты сравнить:
  - `H1/H0_mod(h)` с `H1/H0_meas(h)`;
  - `H2/H0_mod(h)` с `H2/H0_meas(h)`.
- Критерий: сумма квадратов относительных ошибок по всем каналам и высотам.

### 5.3. Обратная задача (подбор параметров)
- Найти параметры `θ` ошибки инклинометра, минимизирующие невязку между моделью и измерениями.
- Параметры:
  - Глобальные параметры инклинометра (одни на весь прибор): `ε_1, ψ_1, ε_2, ψ_2, φ_0`.
  - Возможно, индивидуальные параметры на канал/приёмник, если глобальные не достаточны.
- Ограничения: физически разумные амплитуды ошибки (несколько градусов).

## 8. Ограничения и допущения

- Передатчики считаются вертикальными (`tx_tilt = 0`).
- Корпус прибора влияет только на амплитуду прямого ZZ-сигнала (по теории Долля), но не на отражённый ZX-сигнал.
- Ошибка инклинометра одинакова для всех углов поворота (нет высотозависимого люфта).
- Модель point-dipole без конечных размеров катушек.

## 9. Промежуточные результаты моделирования

### 9.1. Подзадача 1: источник `H2`
- В модели с вертикальным передатчиком **2-я гармоника угловой ошибки** `ε_2·cos(2φ + ψ_2)` не порождает `H2`.
- **1-я гармоника угловой ошибки** `ε_1·cos(φ + ψ_1)` (эксцентриситет/перекос магнетометра) приводит к появлению `H2`.
- Для канала ch0 (`L=0.96` м, `h=0.45` м) амплитуда `ε_1 ≈ 1.9°` даёт `H2/H0 ≈ 0.89%`, что совпадает с измеренным.
- По всем каналам/высотам требуемая `ε_1` для совпадения `H2/H0`:
  - 0.3–2.2° для `L=0.96` м (ch0, ch5);
  - 1.1–5° для `L=1.62–3.00` м.
- Максимальное наблюдаемое отклонение МТФ после перекалибровки ~1° объясняет `H2` только для коротких баз; для длинных баз требуемая `ε_1` превышает 1°. Это либо говорит о нелокальности ошибки, либо о дополнительном механизме (например, амплитудной модуляции wobble).

### 9.2. Подзадача 2: отклонение `H1/H0(h)`
- 2-я гармоника угловой ошибки `ε_2` даже величиной 1–2° практически не меняет `H1/H0(h)`.
- Систематическое отклонение `H1/H0(h)` от теории точечного диполя сохраняется и не объясняется угловой ошибкой МТФ в рамках вертикального передатчика.
- Отклонение, скорее всего, связано с влиянием металлического корпуса (теория Долля), а не с инклинометром.

### 9.3. Подзадача 3: падение `H2` после перекалибровки
- Падение `H2` в ~5 раз после перекалибровки согласуется с уменьшением амплитуды 1-й гармоники угловой ошибки `ε_1` примерно с ~5° до ~1°.
- Если бы доминировала 2-я гармоника `ε_2`, перекалибровка не уменьшила бы `H2` (так как `ε_2` не создаёт `H2` в этой модели).

## 11. Открытые вопросы для продолжения

1. Почему для длинных баз (`L ≥ 2.28` м) требуемая `ε_1` превышает 1°? Возможные варианты:
   - Ошибка МТФ не глобальна, а зависит от положения/канала (разная посадка магнетометра на длинных базах маловероятна).
   - Вклад амплитудной модуляции `a_2` (wobble корпуса) растёт с `h/L` или с `L`.
   - Источник `H2` частично не инклинометр, а другой эффект.
2. Стоит ли попытаться одновременно подобрать `ε_1` и `a_2` по реальным `H2` для всех каналов?
3. Нужно ли включать в модель небольшой наклон передатчика, чтобы 2-я гармоника ошибки `ε_2` тоже могла давать `H2`?
