# Техническое задание по калибровке зонда «Картограф»

## 1. Исходные данные и геометрия зонда
- Измерения амплитуд компонент поля (amp_V_zz, amp_V_zx, amp_V_xx) и разности фаз d_ph_Vzx_Vzz для 8 каналов на наборе высот h над проводящей границей (CSV-файл).
- Рабочие частоты: 400 кГц и 2000 кГц (калибровка проводится раздельно для каждой частоты).
- Приемники: `L` = `Rzx1`, `R` = `Rzx2`.
- Базы каналов: `L = 0.96, 1.68, 2.28, 3.00 м`.
- Геометрические поправки базы ΔL(L) и сдвига высоты Δh не требуются (L_eff = L, dh = 0).
- В расчете используются все доступные высоты без отсечения.

## 2. Физическая модель отклика и влияние корпуса прибора

### 2.1. Распределение компонент поля
В геометрии воздушных измерений над проводящей границей поле зонда складывается из прямого сигнала и отраженного от границы (метод зеркальных изображений):
- **Прямое поле (ZZ / H0, amp_V_zz):** доминирует на малых базах, слабо зависит от высоты h.
- **Отраженное поле (ZX / H1, amp_V_zx):** формируется наклоном приемника beta относительно вертикального излучателя (tx_tilt = 0 град) и затухает с высотой по закону:
  f_air(h, L) = h * L / (L^2 + 4 * h^2)^2.5

### 2.2. Природа паразитной связи через корпус (теория Долля)
Металлический корпус зонда находится в непосредственной близости от катушек. Несмотря на малый геометрический фактор g_corpus, высокая проводимость металла sigma_corpus дает постоянную добавку (произведение g * sigma):
1. Корпус создает прямое прохождение, не зависящее от высоты h (так как путь замкнут внутри прибора).
2. В первой гармонике H1 (компонента ZX) это проявляется как постоянное аддитивное смещение C:
   H1_meas(h, L) = A * f_air(h, L) + C
   где A — общий масштабный коэффициент канала (произведение усиления тракта, токов, моментов катушек и sin(beta)).

### 2.3. Безразмерная корпусная константа c = C / A
Для исключения влияния тока генератора, коэффициентов усиления АЦП и возможности переноса калибровки в проводящий пласт вводится безразмерная константа:
c = C / A

В нормализованном виде отклик канала описывается уравнением:
(H1_meas / A) - c = f_air(h, L)

Величина |c| составляет (2...9) * 10^-4 (0.02%–0.1% от амплитуды сигнала). С ростом высоты h полезный сигнал f_air затухает как ~1/h^4, поэтому неучтенная корпусная добавка C приводила бы к искажению формы кривой H1(h) и ложному уплыванию угла beta. Вычитание C полностью стабилизирует форму отклика.

## 3. Алгоритм калибровки зонда

Калибровка выполняется последовательно в два шага для каждой частоты (400 кГц и 2000 кГц) по всем 8 каналам:

### Шаг 1: Определение корпусной константы c_j = C_j / A_j
По измеренной кривой H1_meas(h) методом взвешенного МНК с весами w = 1 / (H1_meas)^2 определяются параметры прямой A_j и C_j, минимизирующие невязку с функцией f_air(h, L_j).
Фиксируется безразмерный корпусной параметр канала:
c_j = C_j / A_j

### Шаг 2: Определение эффективных углов наклона приёмников beta_j
Из измеренного сигнала H1 вычитается найденное корпусноe смещение C_j = c_j * A_j:
H1_corr(h) = H1_meas(h) - C_j

Эффективный угол наклона приемника beta_j для каждого канала находится минимизацией суммы квадратов невязок отношения гармоник по всем высотам:
сумма [ (H1/H0)_theor(h, L_j, beta_j) - (H1_corr(h) / H0_meas(h)) ]^2 -> min

### Шаг 3: Фиксация разности фаз
Средняя разность фаз d_ph_Vzx_Vzz (в радианах и градусах) фиксируется для каждого канала как дополнительный фазовый калибровочный коэффициент.

## 4. Требования к качеству калибровки
- **Стабильность угла по высотам:** стандартное отклонение вычисленного beta(h) по отдельным высотам внутри канала не превышает 0.3–0.6 град.
- **Симметрия зеркальных пар:** различие углов beta между симметричными каналами одинаковой длины базы составляет не более 1.0–1.8 град на валидных геометриях.
- **Точность описания сигнала:** воспроизводимость формы кривой отклика и минимальная невязка (H1_corr/H0) с теорией.

## 5. Учет 2-й гармоники (H2 / amp_V_xx)
- В идеальной модели с вертикальными излучателями теоретическое отношение H2/H0 = 0.
- Измеренная малая величина H2 вызвана эксцентриситетом / первой гармоникой погрешности инклинометра (~1 град при кодировании угла поворота).
- Вторая гармоника H2 не несет информации о геометрических углах зонда, не используется при подборе beta_j и минимизируется юстировкой инклинометра.

## 6. Выходные параметры калибровки
Для каждой частоты (400 кГц и 2000 кГц):
1. Вектор безразмерных корпусных констант c_j = C_j / A_j (8 значений).
2. Вектор эффективных углов наклона приёмников beta_j в градусах (8 значений).
3. Вектор средней разности фаз d_ph_Vzx_Vzz в радианах и градусах (8 значений).
4. Сводный отчет сходимости (H1_corr/H0)_meas и (H1/H0)_theor по всем высотам и графики калибровки.
