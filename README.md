# NEURO_GEO

Генерация датасета электромагнитного каротажа (empymod) и обучение прямого суррогата
7 параметров пласта -> 40 сигналов зонда.

```
dataset/GEO_40sig_7p_dataset_gen.py     генерация датасета (LHS + empymod -> parquet)
train/forvard_neuro_train_7p_40sig.py   обучение суррогата (PyTorch, экспорт весов в .txt для DLL)
tools/verify_mirror_symmetry.py         проверка симметрии, на которой построена аугментация
docs/                                   разбор исходных версий скриптов и обоснование правок
```

## Модель и данные

Трёхслойная модель: изотропные вмещающие, анизотропный средний пласт.

| параметр | смысл | диапазон |
|---|---|---|
| `Rh_up`, `Rh_pl`, `Rh_dn` | горизонтальные УЭС слоёв, Ом·м | 1 … 1000 (лог-равномерно) |
| `Rv_pl` | вертикальное УЭС пласта | `Rh_pl` × [1 … 5] |
| `D_up`, `D_dn` | расстояния до границ, м | 0.05 … 4 |
| `Alpha` | угол падения, град | 60 … 120 |

40 сигналов = 2 частоты (400 кГц, 2 МГц) × (4 компенсированные ZZ-фазы + 4 разноса × [A_Amp, A_Phase, B_Amp, B_Phase]),
разносы ZX: 0.96 / 1.62 / 2.28 / 3.00 м.

## Ключевое свойство: зеркальная симметрия

Отклик зеркальной модели (`Rh_up<->Rh_dn`, `D_up<->D_dn`, `alpha->180-alpha`) — точное преобразование исходного:
ZZ-каналы не меняются, `|S| -> 1/|S|`, `arg S -> -arg S` (совпадение до 1e-12, `tools/verify_mirror_symmetry.py`).
Поэтому генератор считает физику только для базовой половины точек, а зеркальные строки получает формулой,
и обучение делит train/val по базовой точке, чтобы зеркало не попадало в валидацию к своему близнецу.

Практическое следствие: компенсированные ZZ-каналы принципиально не различают верх и низ —
информацию об ориентации несут только ZX-каналы.

## Запуск

```bash
pip install -r requirements.txt
python dataset/GEO_40sig_7p_dataset_gen.py     # -> dataset_7p_splitZX_40f.parquet
python train/forvard_neuro_train_7p_40sig.py   # -> forward_7p_40_sig_weights/
```

Генерация 5 млн строк — примерно 14 ядро-часов (~20 мс на точку физики, замер на Python 3.12 / empymod 2.6).
Счёт возобновляемый: посчитанные чанки лежат в `temp_chunks/`, повторный запуск их пропускает.

Обучение кладёт в `forward_7p_40_sig_weights/`: `W1..W5.txt` / `b1..b5.txt` (веса лучшей эпохи, транспонированные,
формат `[in, out]`), `best_forward_model.pt`, файлы скейлеров, `preprocess_meta.json` (индексы логарифмируемых
колонок, имена каналов, тип активации) и `val_mae_physical.txt` — ошибка по каналам в дБ и градусах.

Активация — `nn.GELU()` в точном (erf) варианте; в C++-инференсе нужен тот же вариант, а не tanh-приближение.
